Css Colors

Css Colors are used to style:

  • Text
  • Backgrounds
  • Borders
  • Shadows
  • Gradients

Five Main Ways to Write colors in Css

Color Names

Red blue Green Yellow; Gray Purple Gold

Hex Colors

Structure: RRGGBB (RED , GREEN, BLUE)

00: no color

ff: full Color

white black red Green BLUE Aqua purple Yellow

RGB

Range: 0-255

0 =,black white Green yellow Brown green Green Brown yellow

RGBA (Adds Transparency)

A = Alpha (Opacity)

Range: 0 = fully transparent, 1 = fully visible

HSL (HUE, SATURATION, LIGHTNESS)

HUE: color. 0 = red, 120 = green, 240 =BLUE

SATURATION: Intensity. 0% = gray, 100% =full color

LIGHTNESS: 0% = black, 50% = normal, 100%= white
