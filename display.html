Display controls how an element behaves on the page.

display block

This element wants the whole row to themselves. A block element :

  • Takes full width
  • Starts on a new line
  • pushes other element down

Examples : div, p, h1 etc ...

display inline

This element stand beside others . Inline elements :

  • stay on same line
  • only take needed width

examples : span, img, a, strong, etc ...

You can force an inline element to become block
