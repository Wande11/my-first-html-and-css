📦 The CSS Box Model

Every HTML element is a box. This is how that box works.

Concept What is the Box Model?

In CSS, every single element — a heading, a paragraph, a button, an image — is treated as a rectangular box. The box model describes the four layers that make up each box.

From the outside in, those layers are: Margin → Border → Padding → Content

Margin — space outside the border
Border — the visible outline
Padding — space inside the border
Content
🖼️ Text / Images

1 Content — width & height

This is where your actual text, images, or other elements live. You control its size with width and height.

.box { width: 200px; /* how wide the content area is */ height: 100px; /* how tall the content area is */ }
💡
If you don't set a height, the box will grow automatically to fit whatever is inside it. That's usually the best behaviour!

2 Padding — space INSIDE the border

Padding pushes the content away from the border. It makes the box feel less cramped — think of it as breathing room inside.

.box { /* Same padding on ALL four sides */ padding: 20px; /* Different padding top/bottom vs left/right */ padding: 10px 30px; /* Different padding on every single side */ padding-top: 10px; padding-right: 20px; padding-bottom: 10px; padding-left: 20px; /* Shorthand: top right bottom left (clockwise) */ padding: 10px 20px 10px 20px; }

3 Border — the visible edge of the box

The border wraps around the padding and content. You can control its thickness, style, and colour.

.box { /* Shorthand: thickness style colour */ border: 3px solid blue; /* Border styles you can try: */ border: 3px solid red; /* ─────── solid line */ border: 3px dashed red; /* - - - - dashed line */ border: 3px dotted red; /* · · · · dotted line */ /* Round the corners with border-radius */ border-radius: 10px; /* slightly rounded */ border-radius: 50%; /* makes a circle! */ }

4 Margin — space OUTSIDE the border

Margin pushes other elements away from this box. It's invisible — no colour — it's just empty space around the box.

.box { /* Same margin on ALL four sides */ margin: 20px; /* Individual sides — same as padding */ margin-top: 10px; margin-right: 15px; margin-bottom: 10px; margin-left: 15px; /* Centre a box horizontally on the page */ margin: 0 auto; /* top/bottom=0, left/right=auto (equal) */ }
💡
Padding vs Margin? — Padding adds space inside (background colour shows through). Margin adds space outside (always transparent).

⚠️ box-sizing — the important rule every project needs

By default, if you set width: 200px and then add padding: 20px, the actual box ends up 240px wide — confusing! Use box-sizing: border-box to make the width include padding and border.

/* The magic reset — put this at the TOP of every CSS file */ * { box-sizing: border-box; /* Now width: 200px means the TOTAL width is 200px, padding and border are included inside that number. Much easier to predict! */ }

Try It Full Example

Here's a complete example using every box model property together:

/* HTML: <div class="my-card">Hello!</div> */ .my-card { /* CONTENT */ width: 300px; /* 300px wide content area */ /* PADDING — space inside the border */ padding: 20px 24px; /* 20px top/bottom, 24px left/right */ /* BORDER — visible edge */ border: 3px solid steelblue; border-radius: 8px; /* rounded corners */ /* MARGIN — space outside the border */ margin: 30px auto; /* 30px top/bottom, centred left/right */ /* EXTRAS */ background-color: lightyellow; font-size: 1rem; box-sizing: border-box; /* total width stays 300px */ }

More Styling Each Border Side Separately

You don't have to style all four borders the same way. You can target each side on its own!

.box { /* Style only the top border */ border-top: 4px solid red; /* Style only the bottom border */ border-bottom: 4px dashed blue; /* Style only the left border */ border-left: 6px solid green; /* Style only the right border */ border-right: 2px dotted orange; }

A popular trick — a coloured left border accent used on quote boxes:

/* HTML: <blockquote class="quote">Great quote here</blockquote> */ .quote { border-left: 5px solid gold; /* only a left border */ border-top: none; /* remove the other sides */ border-right: none; border-bottom: none; padding-left: 16px; /* push text away from the gold line */ font-style: italic; }

More Padding & Margin Shorthand Patterns

Both padding and margin accept 1, 2, 3, or 4 values. Here's exactly what each pattern means:

.box { /* 1 value — all four sides the same */ padding: 10px; /* top=10 right=10 bottom=10 left=10 */ /* 2 values — top&bottom | left&right */ padding: 10px 20px; /* top=10 right=20 bottom=10 left=20 */ /* 3 values — top | left&right | bottom */ padding: 5px 20px 15px; /* top=5 right=20 bottom=15 left=20 */ /* 4 values — top right bottom left (clockwise!) */ padding: 5px 10px 15px 20px; /* top=5 right=10 bottom=15 left=20 */ /* 🧠 Memory trick: Think of a clock — Top → Right → Bottom → Left */ }

More overflow — what happens when content is too big

If you set a fixed height on a box and the content is too tall to fit, it will spill out by default. The overflow property controls what happens.

.box { width: 250px; height: 80px; /* fixed height — content might not fit! */ /* overflow: visible (default) — content spills outside the box */ overflow: visible; /* overflow: hidden — clips anything that doesn't fit */ overflow: hidden; /* overflow: scroll — always shows scrollbars */ overflow: scroll; /* overflow: auto — only adds scrollbars when needed (best!) */ overflow: auto; /* You can also control x and y separately */ overflow-x: hidden; /* hide horizontal overflow */ overflow-y: auto; /* scroll vertically if needed */ }

More min-width, max-width, min-height, max-height

Instead of a fixed size, you can give a box a minimum or maximum size. This makes your layout work on both small phones and large screens.

.card { /* The box is 100% wide BUT never wider than 600px */ width: 100%; max-width: 600px; /* The box is at least 80px tall, but can grow bigger */ min-height: 80px; /* The box will never exceed 400px tall — scrolls after that */ max-height: 400px; overflow-y: auto; /* scroll if content exceeds max-height */ padding: 20px; border: 2px solid teal; } /* Great pattern for readable articles — don't let lines get too wide */ .article { width: 100%; max-width: 680px; /* comfortable reading width */ margin: 0 auto; /* centre it on the page */ padding: 0 20px; /* side padding on small screens */ }

Fun Making Shapes with the Box Model 🔵

Combine width, height, and border-radius to make cool shapes!

/* ─── CIRCLE ──────────────────────────────────── */ .circle { width: 100px; height: 100px; /* must be equal to width! */ border-radius: 50%; /* 50% makes it a perfect circle */ background-color: tomato; } /* ─── PILL / BADGE ─────────────────────────────── */ .pill { display: inline-block; padding: 6px 18px; border-radius: 999px; /* very large radius = pill shape */ background-color: mediumseagreen; color: white; font-size: 0.85rem; } /* ─── AVATAR / PROFILE PICTURE ─────────────────── */ .avatar { width: 80px; height: 80px; border-radius: 50%; /* circle */ border: 3px solid white; /* white ring around photo */ object-fit: cover; /* crop image to fit without stretching */ }

Project Real World Example — A Profile Card 🪪

Let's use everything we've learned to build a proper profile card from scratch.

/* ── HTML ───────────────────────────────────────────── <div class="profile-card"> <div class="avatar"></div> <h3 class="name">Alex Kim</h3> <p class="role">Web Developer</p> <button class="follow-btn">Follow</button> </div> ──────────────────────────────────────────────────── */ /* The outer card */ .profile-card { width: 220px; padding: 32px 24px; /* space inside the card */ border: 1px solid #ddd; border-radius: 16px; /* rounded card corners */ margin: 40px auto; /* centre the card on page */ text-align: center; background-color: white; box-shadow: 0 4px 20px rgba(0,0,0,0.08); } /* Profile photo — circle using border-radius */ .avatar { width: 80px; height: 80px; border-radius: 50%; /* makes it a circle */ border: 3px solid royalblue; /* ring around photo */ margin: 0 auto 16px; /* centred, 16px below */ background-color: #e0e7ff; /* placeholder colour */ } /* Name text */ .name { margin-bottom: 4px; /* small gap under the name */ font-size: 1.1rem; } /* Role / job title */ .role { margin-bottom: 20px; /* gap before the button */ color: #888; font-size: 0.85rem; } /* Follow button */ .follow-btn { padding: 10px 28px; /* space inside button */ border: none; border-radius: 999px; /* pill shape */ background-color: royalblue; color: white; font-size: 0.9rem; cursor: pointer; } /* Hover effect on button */ .follow-btn:hover { background-color: darkblue; /* darker when mouse is over it */ }

Watch Out Common Mistakes & How to Fix Them 🐛

/* ❌ MISTAKE 1: Forgetting box-sizing */ .box { width: 200px; padding: 20px; /* Actual rendered width = 200 + 20 + 20 = 240px 😱 */ } /* ✅ FIX: Always add this reset at the top of your file */ * { box-sizing: border-box; } .box { width: 200px; padding: 20px; /* Actual rendered width = 200px exactly ✅ */ } /* ❌ MISTAKE 2: Using margin when you want padding */ .button { margin: 20px; /* this pushes OTHER elements away, not your text! */ } /* ✅ FIX: Use padding to create space inside the button */ .button { padding: 12px 24px; /* space around the text INSIDE the button ✅ */ } /* ❌ MISTAKE 3: Setting height when you don't need to */ .card { height: 200px; /* if content grows, it overflows! */ } /* ✅ FIX: Let height grow naturally, or use min-height */ .card { min-height: 200px; /* at least 200px, but grows if needed ✅ */ padding: 24px; } /* ❌ MISTAKE 4: Forgetting margin: 0 auto to centre a box */ .container { width: 600px; /* why isn't it centred?? */ } /* ✅ FIX: Add margin auto */ .container { width: 600px; margin: 0 auto; /* now it's centred! ✅ */ }
