Introduction To Web Development

Web Development is the process of building and maintaining websites.

Types Of WebDev

  1. Font-End Development

    • What Users See On The Browser
    • Languages: HTML, CSS, JAVASCRIPT
    • Example:Layout, Colours, Buttons, Fonts.

  2. Back-End Development

    • The Behind-the-scenes logic and database.
    • Languages: PHP, PYTHON, NODE..IS
    • Examples:Logic System, Data Storage.

  3. Full-Stack Development

    • It is the Combination of Front-End And Back-End

TOOLS

  1. Text Editor: VS Code, Notepad, PyCHARM, ETC
  2. Web Browser: Chrome, Firefox, ETC
  3. Version Control:GIT & GITHUB (For Saving And Sharing Code)

Key Concepts

  • HTML (Hypertext Markup Language) - Structure Of the Webpage
  • CSS (Cascading Style Sheet) - Styling The Structure.
  • JAVASCRIPT - Making It Interactive
  • Responsive Design - Mobile-Friendly Layout
  • Hosting - Making Your website Live

HTML Elements

  1. Block Elements - They take up the full width of the page. Examples: h1, p, div, section
  2. Inline Elements-They only take up as much space as needed.Examples: button, a, img, span, strong etc...

DIV

Div stands for division.
It is a Container used to group HTML elements together.
It has no visual appearance on its own.
It helps with layout and styling.
It is used to organise your content.
To also apply Css styles to a section of your page.

website

A website is a collection of webpages that are connected together and can be accessed through the internet using a browser.

Types Of website

  1. Static Website - Just show Information. Examples: posters online, a school website with basic info.
  2. Dynamic Website - Change depending on what users do. Examples: Facebook, Youtube, Instagram, Tiktok & Twitter.
