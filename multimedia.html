HTML Multimedia

HTML Multimedia is the topic that covers adding audio, videos and images and other media content to a webpage.

images

Common attributes:

  • controls → shows play/pulse buttons
  • autoplay → starts automatically
  • loop → repeats foreover
  • muted &arr; video/audio stays muted
  • width
  • height
  • poster → displays a cover image before the video plays
  • src → image/video/audio location
  • alt→ alternativetext
  • type→ video/audio type. e.g mp3, mp4,mpeg etc.
