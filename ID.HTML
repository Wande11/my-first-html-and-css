ID

An ID is a unique identifier you give to an Html element. You can use it to target,style, or manipulate that specific element.

Each ID should be unique - only one element on a page should have the same ID.

  1. Using ID in CSS → To style an element with an ID,use the # symbol followed by the ID name.
  2. Jumping Through Sections (Page Navigation) →You can use IDs to Jump to different sections on page .
